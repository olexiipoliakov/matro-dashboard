# Методика разбора DEAL_*.xls (дневной отчёт по заказам)

Эта методика используется вручную в чате для расчёта дневного товарооборота Matro.
Задача: перенести ту же логику в дашборд (fetch_bitrix.py / bitrix.html), чтобы она
считалась автоматически из тех же данных, что тянутся из Bitrix24.

## Входные данные

Файл `DEAL_YYYYMMDD_*.xls` — экспорт сделок из CRM (по факту HTML-таблица с
расширением .xls). Одна строка = одна товарная позиция внутри сделки (у одной
сделки может быть несколько строк — сам товар + доставка + наложка и т.д.).

Ключевые колонки: `ID` (номер сделки), `Стадия сделки`, `Товар` (название позиции),
`Сумма`, `Источник`, `Дата создания`.

## Шаг 1 — Исключить нерелевантные сделки целиком

Убрать ВСЕ строки, где `ID` относится к сделке со стадией:
- `Отказ клиента` — клиент отказался, это не продажа
- `Ошибочный` — ошибочно созданная сделка/дубль

(Сделки со стадией `Заказ`, `Заказ проведен оператором`, `Товар оплачен`,
`Заказ отгружен клиенту`, `Сделка успешна` — все считаются как обычные заказы.)

## Шаг 2 — Исключить строки-услуги (не товар)

Внутри оставшихся сделок убрать строки, где `Товар` содержит (регистронезависимо):
`наложк`, `наложен`, `наклад` (в т.ч. опечатки: `налокж`, `достак`, `доствк`,
`3анос` вместо `занос`), `доставк`, `занос`, `виніс`, `підйом на поверх`,
`послуга збірки`, `збірка в день`.

Это доставка, наложенный платёж, занос на этаж, подъём, сборка — не товарная выручка.

## Шаг 3 — Категоризация оставшихся товарных строк

По ключевым словам в названии товара (регистронезависимо), в этом порядке
приоритета (первое совпадение побеждает):

1. **Аксессуары** (не входят в 4 основные категории, считаются отдельной строкой,
   не в "обороте по категориям", но входят в общий оборот дня):
   `наматрацник`, `наматрасник`, `подушк`, `ковдра`, `підматрацник`,
   `подматрасник`, `чохол-сумка`, `чехол-сумка`
2. **Шкафы**: `шафа`, `шкаф`, `антресоль`, `пенал`
3. **Корпусная мебель** (тумбы, прихожие, столы): `тумба`, `передпокій`,
   `прихож`, `стіл`, `стол`
4. **Мягкая мебель** (диваны, кровати, подиумы, комплекты кровать+матрас):
   `ліжко`, `кровать`, `диван`, `подіум`, `крісло`, `каркас`, `комплект`
5. **Матрасы** (топперы, футоны, ортопедические): `матрац`, `матрас`, `топпер`,
   `топер`, `ортопед`, `футон`

## Шаг 4 — "Голые" названия моделей матрасов

Много позиций — это просто название модели без слова "матрац" (например:
`Азалія 160*200`, `Бордо 160х190`, `Аура кокос 90*190 скрутка`, `Гранат кокос`,
`Мохо, 160х200`). Такие строки после шага 3 попадают в "нераспознанные" —
их нужно вручную сверить со списком уже известных названий матрасных моделей
(Azalia/Азалія, LEO/LEO Kokos, Provance/Прованс, Bordo/Бордо, Aura Kokos/Аура
Кокос, Traffic/Трафік, Diamond/Діамант, Leeds, Retreat/Ретріт, Camelia/Камелія,
Amore/Амор, Meditation, Light Kokos и др.) и, если совпадает — засчитать как
матрас. Полного фиксированного списка нет, пополняется по ходу разбора файлов;
для автоматизации в дашборде разумнее держать растущий список известных
моделей матрасов в отдельном файле/константе.

## Шаг 5 — Комбо-позиции (кровать + матрас в одной строке)

Строки вида `Ліжко ТЕО 160x200 + матрас LEO, ...` или `Комплект ліжко САН + LEO`
— это ОДНА товарная позиция (кровать с матрасом внутри), считается целиком как
**мягкая мебель**, не разбивается на матрас+мебель отдельно.

## Шаг 6 — Подсчёт количества заказов

Количество заказов за день = количество **уникальных ID сделок**, оставшихся
после шага 1 (не считать строки — считать сделки).

## Шаг 7 — Разбивка по источникам

Взять уникальные сделки (после шага 1), сгруппировать по `Источник`
(WEB, Звонок, Обратный звонок, WEB - Зворотний дзвінок, Jivosite, Instagram,
Facebook, Розетка, Розетка симплер, Заявка, Заявка симплер, Епіцентр, другое/
не указан) — посчитать количество сделок на каждый источник.

## Шаг 8 — Флаги аномалий (не исключать, но подсвечивать отдельно)

- **Опт/крупная партия**: одна позиция с большим количеством штук и суммой,
  сильно выбивающейся из обычного среднего чека (пример: 44 шт одной модели
  матраса на 169 000 грн, или 3 позиции по 31/68/59 шт на 361 000 грн) —
  показывать оборот и с ней, и без неё.
- **Пометка "службовка"** в названии товара — похоже на внутреннюю/служебную
  позицию, не обычную розничную продажу — подсвечивать отдельно, не исключать
  автоматически без подтверждения.
- **Товар = NaN / пустая строка** с ненулевой суммой — обычно дубль или
  ошибка выгрузки, требует ручной проверки.

## Итоговый формат вывода на день

1. Кол-во заказов (после исключений)
2. Общий оборот (без доставки/наложки/заноса)
3. Разбивка по 4 категориям (матрасы / мягкая мебель / шкафы / корпусная)
4. Аксессуары отдельной строкой (не входят в 4 категории)
5. Разбивка по источникам
6. Если есть — флаг аномалии (опт/службовка) с суммой день с ней и без неё

## Открытые вопросы / решения, принятые по ходу (стоит захардкодить так же)

- Компьютерный/письменный стол (без явного "тумба/прихожая") — относить к
  **корпусной мебели** за неимением отдельной категории "столы".
- Чехол-сумка на матрас, наматрасник, подушки — это **аксессуары**, не матрасы
  и не входят в 4 основные категории, даже если в названии есть слово "матрас".
- Каркас (ліжка) на ламелях без матраса — это **мягкая мебель** (кроватный
  каркас), аналогично полноценной кровати.
- Гарантийные/сервисные заявки с суммой 0 (подрезка фасада, замена петли и
  т.п.) — не продажа, не считаются ни в одной категории.
